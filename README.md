# BulkAgrochemApp – Android E-commerce Application

## Project Overview
BulkAgrochemApp is an Android-based B2C e-commerce application developed during my internship at **Unicrop Biochem Pvt. Ltd.**

I independently developed this application as the sole intern working on the project, gaining practical experience in Android application development, API integration, database handling, and payment gateway integration.

## Key Features
- Android-based e-commerce application
- REST API integration
- Razorpay payment gateway integration
- JSON data parsing and handling
- MySQL database integration
- Application module development and debugging

## Technology Stack
- **Programming Language:** Java
- **Development Environment:** Android Studio
- **API Integration:** REST APIs
- **Data Format:** JSON
- **Database:** MySQL
- **Payment Gateway:** Razorpay
- **Version Control:** Git and GitHub

## My Responsibilities
- Independently developed the Android application during my internship.
- Integrated backend APIs with the Android application.
- Implemented Razorpay payment gateway integration.
- Worked with JSON responses and MySQL-backed application data.
- Developed application modules and performed debugging.
